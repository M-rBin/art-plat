## 二、项目概述

### 2.1 项目背景

随着中法艺术交流日益频繁，艺术家在跨境合作中需要统一、专业的数字档案来展示个人履历、联系方式与创作资料。当前艺术家档案分散在邮件、社交账号与纸质材料中，存在以下挑战：

1. **档案信息分散**：出生信息、联系方式、代理画廊、引言与资料文件缺乏统一入口，合作方难以快速获取完整信息。
2. **双语展示需求突出**：面向中法市场的艺术家平台需要法文与中文并行的标签与内容展示，传统单语系统难以满足。
3. **身份准入缺失**：档案涉及艺术家隐私与商业信息，需通过注册与邮箱确认建立可信账号体系，避免匿名访问。
4. **资料管理不规范**：肖像、工作室、简历、作品集、媒体报道等资料类型多样，缺乏分类展示与上传规则约束。

为解决上述问题，建设巴黎臻藏艺术家平台（art-plat），为签约艺术家提供登录后可访问的双语档案展示与编辑能力，并为后续对话、展览等模块预留导航结构。

### 2.2 项目建设目标

本项目旨在建设一套面向艺术家的 Web 档案平台，实现以下目标：

1. **可信账号体系**：支持邮箱注册、邮件确认与密码登录，未完成邮箱确认的账号禁止登录，保障档案访问安全。
2. **完整档案展示**：登录后以只读方式集中展示艺术家头部信息、个人信息、联系方式、代理画廊、中国引言及已上传资料清单，支持跳转编辑。
3. **档案自助维护**：提供档案编辑页，支持维护个人信息、联系方式、代理画廊及五类资料上传，并定义文件格式与大小限制。
4. **双语一致体验**：全站操作按钮与字段标签采用法文在前、中文在后的双语呈现，与品牌「巴黎臻藏 / ZHEN Collection Paris」定位一致。
5. **可扩展导航框架**：侧边栏预留对话、展览、臻藏推荐等入口，当前仅「我的档案」可用，为后续迭代留出结构空间。

### 2.3 项目建设范围

本项目建设范围包括：

**系统端**：

- PC 端 Web 应用（website 项目，浏览器访问）

**功能模块**：

- 用户认证：注册、邮箱确认、登录、登录态访问控制
- 艺术家档案展示：档案只读首页、侧边导航、资料清单展示
- 艺术家档案编辑：个人信息、联系方式、代理画廊、资料上传与保存/取消

**数据范围**：

- 艺术家账号（邮箱、密码、确认状态）
- 艺术家档案（个人信息、联系方式、代理画廊、中国引言、资料文件元信息）

**不包含的功能**：

- 忘记密码、社交账号登录、重发确认邮件
- 侧边栏除「我的档案」外的 6 个导航模块（对话、展览、臻藏推荐、搜索、关于我们、联系我们）
- 展示页资料「查看」「编辑」及底部「上传资料」的实际业务逻辑（当前为占位）
- 编辑页「更换头像」的实际上传逻辑（当前为占位）
- 档案保存后的服务端数据写入（当前保存为模拟延迟后返回展示页，修改不落库）

### 3.5 功能详细设计

### 3.5.1 用户认证

**（一）功能需求概述**

用户认证模块负责平台账号的注册、邮箱激活与登录全流程管理。新用户通过邮箱注册账号，注册完成后须通过确认邮件中的激活链接完成邮箱验证，激活后方可登录使用平台功能。未登录用户访问需要权限的功能页面时，自动跳转至登录页面；已登录用户访问登录页或注册页时，自动跳转至个人档案页。

**（二）功能设计**

**登录功能**

用户在登录页面填写邮箱和密码，点击登录按钮完成身份验证。

| 字段名称 | 类型 | 长度限制 | 必填 | 默认值 | 说明 |
|---------|------|---------|------|-------|------|
| 邮箱 | 文本输入 | - | 是 | - | 须符合邮箱格式 |
| 密码 | 密码输入 | 至少 8 位 | 是 | - | 输入内容不可见 |

登录成功：跳转至艺术家档案展示页（若登录前曾访问受保护页面，则返回该页面）。
登录失败：保留已填写内容，显示"邮箱或密码错误"。

**注册功能**

用户在注册页面填写邮箱、密码及确认密码，点击注册按钮提交申请。

| 字段名称 | 类型 | 长度限制 | 必填 | 默认值 | 说明 |
|---------|------|---------|------|-------|------|
| 邮箱 | 文本输入 | - | 是 | - | 须符合邮箱格式，全局唯一 |
| 密码 | 密码输入 | 至少 8 位 | 是 | - | 输入内容不可见 |
| 确认密码 | 密码输入 | 至少 8 位 | 是 | - | 须与密码字段完全一致 |

提交成功：系统向注册邮箱发送确认邮件，页面提示"我们已向 [邮箱] 发送确认邮件，请点击邮件中的链接完成注册"，并提供前往登录入口。
提交失败：保留已填写内容，显示具体错误原因。

**邮箱确认功能**

用户点击注册确认邮件中的激活链接，进入邮箱确认页面，系统自动完成账号激活。

- 确认中：显示"正在确认邮箱…"
- 激活成功：提示"邮箱确认成功，现在可以登录了"，并提供前往登录入口。
- 链接无效：提示"确认链接无效，请重新注册"，并提供重新注册与前往登录入口。
- 链接过期或已使用：提示"确认链接无效或已过期"或"确认链接已过期，请重新注册"。
- 邮箱已确认：提示"该邮箱已完成确认，请直接登录"。
- 网络异常：提示"网络异常，请稍后重试"。

**业务规则**

- 邮箱为空时，阻止提交，提示"请输入邮箱"。
- 邮箱格式不符时，阻止提交，提示"请输入有效的邮箱地址"。
- 密码为空时，阻止提交，提示"请输入密码"。
- 密码长度不足 8 位时，阻止提交，提示"密码至少需要 8 位"。
- 确认密码为空时，阻止提交，提示"请确认密码"。
- 确认密码与密码不一致时，阻止提交，提示"两次输入的密码不一致"。
- 注册时邮箱已被其他已激活账号使用，阻止提交，提示"该邮箱已注册，请直接登录"。
- 注册时邮箱已提交但未完成确认，阻止重复提交，提示"该邮箱已提交注册，请查收确认邮件"。
- 未完成邮箱确认的账号禁止登录；尝试登录时拒绝，提示"邮箱尚未确认，请先查收确认邮件"。
- 登录时邮箱或密码错误，统一提示"邮箱或密码错误"，不区分邮箱不存在与密码错误两种情况。
- 已登录用户访问登录页或注册页时，自动跳转至艺术家档案展示页。
- 未登录用户访问需要登录权限的功能页面时，自动跳转至登录页面。

**边界与异常**

- **邮箱未激活**：尝试登录时拒绝操作，显示"邮箱尚未确认，请先查收确认邮件"。
- **邮箱已注册**：注册时填写的邮箱已存在且已激活，阻止提交，提示"该邮箱已注册，请直接登录"。
- **确认链接失效**：链接缺失、过期或已被使用，显示对应错误文案，引导重新注册或前往登录。
- **未登录访问受保护页面**：系统自动将用户跳转至登录页面。
- **已登录访问登录/注册页**：系统自动将用户跳转至艺术家档案展示页。

**（三）业务逻辑关联**

- 账号须完成邮箱激活后方可访问档案展示与编辑；未激活账号在任何档案入口均不可用。
- 登录状态贯穿全站，档案相关页面均依赖本模块的身份验证结果。
- 本模块不包含忘记密码、社交账号登录、重发确认邮件等功能，上述能力待后续版本规划。

### 3.5.2 艺术家档案展示

**（一）功能需求概述**

艺术家档案展示页是平台登录后的默认首页，以只读方式集中呈现艺术家的完整档案信息。页面包含品牌标识、侧边导航、艺术家身份头部、个人信息、联系方式、代理画廊、中国引言及已上传资料八个内容区块，供艺术家本人核查档案全貌，并支持跳转至编辑页对档案进行修改。

**（二）功能设计**

**侧边导航栏**

侧边导航栏包含 7 个导航项目：

| 导航项（法文 / 中文） | 状态 | 说明 |
|---------------------|------|------|
| Mon profil / 我的档案 | 可用，当前选中 | 对应本展示页，高亮标识当前位置 |
| Dialogues / 对话 | 预留，不可点击 | 入口可见但不响应操作 |
| Expositions / 展览 | 预留，不可点击 | 入口可见但不响应操作 |
| Recommandations / 臻藏推荐 | 预留，不可点击 | 入口可见但不响应操作 |
| Recherche / 搜索 | 预留，不可点击 | 入口可见但不响应操作 |
| À propos / 关于我们 | 预留，不可点击 | 入口可见但不响应操作 |
| Contact / 联系我们 | 预留，不可点击 | 入口可见但不响应操作 |

**顶部品牌栏**

页面顶部展示平台品牌标识（ZHEN / Collection Paris / 巴黎臻藏），并提供「返回目录」操作，点击后返回上一浏览页面。

**艺术家头部信息**

| 展示项 | 说明 |
|-------|------|
| 头像 | 艺术家个人照片 |
| 姓名 | 艺术家全名 |
| 职位 | 艺术家的职业角色（如 Artiste） |
| 国籍与所在城市 | 国籍及当前所在城市，国籍前展示对应国旗 |
| 编辑档案 | 跳转至档案编辑页的入口 |

**个人信息区块**

以双语标签形式展示 5 项艺术家个人信息：

| 字段（法文 / 中文） | 说明 |

| Date de naissance / 出生年月 | 出生年份或年月 |
| Lieu de naissance / 出生地 | 出生城市与国家 |
| Résidence actuelle / 现居地 | 当前居住城市与国家 |
| Expérience à l'étranger / 留学经历 | 海外学习或驻留经历，无则显示占位符 |

## 四、技术方案

- 前端：Vue 3 + TypeScript + Vite，单页 Web 应用

- 未登录用户不可访问档案展示与编辑

- 邮箱须完成确认后方可登录
